Configuration

How it works:

This page sets window.ESCAPP_APP_SETTINGS matching the Escapp server structure:

{
  solutionLength: 1,
  escappClientSettings: {
    endpoint: "https://escapp.es/api/escapeRooms/320",
    linkedPuzzleIds: [2],
    silent: true,
    user: { email: "...", token: "..." }
  }
}

To test with Escapp: Enter your endpoint, puzzle ID, and user credentials (email + token from Escapp).

Note: Without valid credentials, the ESCAPP client will show an authentication dialog.
